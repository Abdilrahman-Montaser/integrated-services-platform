# تدوير هب | Tadweer Hub

منصة B2B لبيع وشراء بواقي وفائض الأقمشة بين المصانع والورش، مع **محفظة ضمان** و**كود استلام** يحمي الطرفين.

> مشروع التخرج، مبادرة Digital Egypt (DEPI) · مسار .NET

---

## المشكلة

- المصانع عندها بواقي أقمشة وأثواب فائضة بتتباع بشكل عشوائي أو بتتراكم من غير قيمة.
- الورش الصغيرة بتدوّر على خامات بسعر مناسب، لكن الشراء بيتم بالتليفون والكاش من غير أي ضمان.
- الدفع قبل الاستلام بيعمل مخاطرة على المشتري، والتسليم من غير تأكيد بيعمل مخاطرة على البائع.

## الحل

المصنع بيعرض **لوط** بوزنه وسعره، والورشة بتشتريه، والفلوس بتتحجز في **محفظة الضمان** ومبتروحش للمصنع غير بعد تأكيد التسليم.

```
المصنع ينشر اللوط  ←  الورشة تشتري (الفلوس تتحجز)  ←  السائق يوصّل  ←  الورشة تسلّم الكود للسائق  ←  السائق يدخله  ←  الفلوس تتحرر للمصنع
```

## الأدوار

| الدور | بيعمل إيه |
|---|---|
| **مصنع** | ينشر اللوطات ويتابع الطلبات |
| **ورشة** | تتصفح اللوطات وتشتري وتدير محفظتها |
| **سائق** | يستلم الشحنة، ويدخل كود الاستلام عند التسليم |
| **أدمن** | يراجع أوراق الحسابات ويوافق أو يرفض |

## المميزات (النسخة الأولى)

- تسجيل ودخول بأدوار (ASP.NET Core Identity)
- توثيق حسابات المصانع برفع السجل التجاري والبطاقة الضريبية، والأدمن بيوافق
- إضافة اللوطات (الخامة، الوزن، السعر، المحافظة، الصور) والبحث والفلترة
- الشراء بمحفظة ضمان (رصيد متاح ورصيد محجوز)
- مسار الطلب: تم الدفع ← في الطريق ← تم التسليم
- كود استلام من 6 أرقام: الورشة تشوفه والسائق هو اللي يدخله
- شاشات الأدمن

**قواعد ثابتة:**
- السعر الإجمالي = سعر الكيلو × الوزن المعلن.
- الدفع داخل المنصة تجريبي (شحن المحفظة بزرار)، من غير بوابة دفع حقيقية.

## التقنيات

- ASP.NET Core MVC
- Entity Framework Core (Code First + Migrations)
- ASP.NET Core Identity
- SQL Server LocalDB
- HTML / CSS مبني على تصميم الواجهة (عربي RTL، خط IBM Plex)

## تشغيل المشروع

المتطلبات: Visual Studio مع ASP.NET workload، و SQL Server LocalDB.

```bash
git clone <رابط-الريبو>
cd TadweerHub
```

1. افتح الـ solution في Visual Studio.
2. تأكد إن الـ connection string في `appsettings.json` بتشاور على LocalDB:
   `Server=(localdb)\MSSQLLocalDB;Database=TadweerHub;Trusted_Connection=True;`
3. افتح Package Manager Console ونفّذ:
   ```
   Update-Database
   ```
4. شغّل المشروع (F5).

الداتابيز بتتبني تلقائياً، والبيانات التجريبية (الأدوار والحسابات واللوطات) بتتضاف عند أول تشغيل بعد ما الـ Seeder يتضاف.

> ممنوع مشاركة ملفات الداتابيز أو تعديل الجداول من برا. أي تغيير في الجداول بيتم عن طريق Migration.

## هيكل المشروع

```
Controllers/        # المتحكمات
Models/Entities/    # كلاسات الجداول
Models/Enums/       # الحالات والأنواع
Data/               # DbContext و Seeder
Services/           # منطق الأعمال (المحفظة، حالات الطلب)
Views/              # صفحات Razor
wwwroot/            # CSS والصور
```

## قواعد العمل على Git

- كل واحد بيشتغل على فرع باسمه، مثلاً.
- محدش يرفع على `main` مباشرة. التعديلات بتدخل بـ Pull Request واحد على الأقل يراجعه.
- `main` لازم يفضل شغال دايماً.
- قبل ما تبدأ: `git pull origin main`.
- ملفات `bin/` و `obj/` و `.vs/` مرفوضة (موجودة في `.gitignore`).
